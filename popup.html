Acciones

Ayuda rápida

Flujo recomendado

  1. Abra un informe de laboratorio del paciente en el sistema clínico.
  2. Presione Leer orden actual para guardar esa orden.
  3. Repita el proceso con otras órdenes del mismo paciente si desea construir la serie longitudinal.
  4. Presione Ver resumen longitudinal para abrir la matriz clínica.

Botones principales

  • Leer orden actual: extrae la orden visible desde el informe abierto.
  • Ver resumen longitudinal: abre la visualización integrada del paciente actual.
  • Exportar CSV: genera una matriz tabular útil para revisión o análisis externo.
  • Exportar JSON: guarda el registro completo de un paciente.
  • Importar JSON: reconstruye un paciente desde un archivo exportado previamente.
  • Exportar respaldo global: guarda todos los pacientes almacenados en la extensión.
  • Importar respaldo global: restaura todos los pacientes desde un respaldo global.

¿CSV, JSON paciente o respaldo global?

  • CSV: para revisar la matriz en formato tabular.
  • JSON paciente: para trasladar o respaldar un solo paciente.
  • Respaldo global: para proteger o restaurar todo el registro local de la extensión.

Problemas frecuentes

  • Si la extracción falla, verifique que el informe de laboratorio esté realmente abierto en el navegador. Si se encuentra en un informe válido, vuelva a cargar o actualice la página de informes.
  • Si no aparece un paciente, primero extraiga al menos una orden válida.
  • Si actualiza la extensión, el respaldo global permite recuperar el registro si fuera necesario.
